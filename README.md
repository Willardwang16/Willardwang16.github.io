# 加密文档访问站点

本仓库只保存加密文件和浏览器阅读页面，不保存未加密论文或解密密钥。

## 文件说明

| 路径 | 用途 |
| --- | --- |
| `icdm-2026-s30317/index.html` | ICDM 2026、论文编号 S30317 的正式阅读页面 |
| `icdm-2026-s30317/ICDM_S30317_Paper.pdf.enc` | 正式论文的加密文件，不能直接当作 PDF 打开 |
| `archive/initial-upload/` | 最初上传版本的备份 |
| `404.html` | 兼容旧二维码中的随机地址，保留访问链接中的解密信息 |
| `index.html` | 网站根目录提示页，不展示论文入口 |
| `robots.txt` | 请求搜索引擎不要收录站点 |
| `.nojekyll` | GitHub Pages 静态文件发布标记 |

需要完整二维码链接才能在浏览器里解密阅读。请勿将包含解密信息的完整链接、二维码图片或密钥提交到此仓库。
